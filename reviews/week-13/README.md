# [Week 13] Tool Use & Autonomous Agent Guardrails (Track 4 개막)

- **주제**: 모델이 도구·셸·브라우저·네트워크로 실제 행동할 때 피해의 상한을 묶는 법. 위협 3분류(사용자 오용 · 모델 오작동 · 외부 공격자) × 방어 3구성요소(환경 · 모델 · 외부 콘텐츠), 격리 3패턴, auto mode 행동 분류기 해부, 2026년 여름 에이전트 사고와 평가 환경 봉쇄 실무, 그리고 국내 첫 에이전트 보안 지침(과기정통부·KISA 에이전틱 AI 제로트러스트 안내서)과의 대응
- **리뷰 일자**: 2026-11-09 (월) 회차 · 2026-11-10 작성
- **트랙**: Track 4 — Sovereign AI & Practical Application (**Track 4 개막**)
- **난이도**: 🟡 중급

## 🎯 학습 목표
1. 에이전트의 네 구성요소(모델 · 하네스 · 도구 · 환경)와 **위협 3분류 × 방어 3구성요소** 를 구분하고, lethal trifecta · Rule of Two가 가리키는 **폭발 반경의 정의**를 이해한다.
2. 프롬프트 인젝션 강건성 수치를 **ASR@1(단일 시도)과 ASR@k(적응형 k회)** 로 나눠 읽고, 모델 계층이 "확률"을, 환경 계층이 "상한"을 바꾼다는 차이를 설명한다.
3. 임시 컨테이너 · 사람 승인 + 샌드박스 · 봉인 VM 세 격리 패턴의 비용과 폭발 반경을 비교하고, **격리 강도를 사용자의 감독 능력에 맞추는** 원칙을 적용한다.
4. auto mode의 **추론 맹목(reasoning-blind) 2단 분류기** 설계와 **오차단 0.4% / 미탐 17%** 의 의미, 그리고 실제 사고 백테스트(66% vs 7%)가 보여주는 분류기의 맥락 의존성을 이해한다.
5. 2026년 여름 사고(평가 설정 오류 · OpenAI 샌드박스 탈출 · UK AISI)에서 **"평가 환경도 배포 환경"** 이라는 교훈과 평가 파트너 봉쇄 관행(사전 탈출 시험 · 해결 가능성 확인 · 범위 지시문 · 실시간 감시)을 도출한다.
6. KISA 안내서의 4개 검증 지점(입력 처리 · 도구 호출 · 작업 위임 · 외부 통신)을 실제 구현에 대응시키고, 소버린 AI 조직의 **"환경 먼저"** 단계별 도입 경로를 세운다.
